# AI 금융보안 비서

**2026 금융 AI Challenge 제출작**

---

## 1. 문제 정의 (현안)

생성형 AI 등장 이후 금융사기 수법이 빠르게 고도화되고 있다.

- 유명인·전문가의 얼굴과 목소리를 딥페이크로 합성한 가짜 투자 리딩방 홍보가 실제로 사회적 문제가 되었고, 금융감독원도 관련 소비자 경보를 발령한 바 있다.
- LLM을 이용해 대량 생성한 피싱 문자·스미싱은 기존의 고정 패턴/키워드 기반 필터를 쉽게 우회한다.

**공격자는 이미 생성형 AI를 사기 도구로 활용하는데, 방어는 여전히 정적인 규칙 기반 필터에 머물러 있다는 비대칭이 이 프로젝트가 풀고자 하는 현안이다.**

## 2. 솔루션 개요 — "AI 레드팀 vs AI 블루팀"

기존 사기 탐지 서비스는 이미 알려진 패턴만 탐지한다는 한계가 있다. 본 서비스는 **레드팀 AI가 최신 사기 트렌드를 반영한 공격 샘플을 스스로 생성**하고, **블루팀 AI가 이를 실시간으로 탐지**하는 대립 구조를 통해 진화하는 위협에 대응한다.

| 구성 요소 | 역할 |
|---|---|
| 레드팀 AI | 딥페이크 투자 리딩방 스크립트, AI 생성 피싱 문자 등 가상 공격 샘플을 생성 (데모/검증 전용, 실제 유포 없음) |
| 블루팀 AI — 이상거래 탐지 | 거래 패턴 기반 정형 데이터 이상탐지 (지도학습 모델) |
| 블루팀 AI — 콘텐츠 판별 | 문자·메시지가 AI 생성 사기 콘텐츠일 가능성을 실시간 판별 |
| 대응 비서 | 탐지 결과를 위험도별 맞춤 행동요령으로 변환해 즉시 안내 |

## 3. 핵심 기능

1. **이상거래 탐지 엔진** — 카드도용·계좌탈취 등 이상거래 패턴을 학습한 지도학습 모델. 공개 벤치마크 데이터(신용카드 거래 28만여 건, 사기 비율 0.17%)로 학습, SMOTE로 불균형을 보정하되 **평가는 원본 비율의 테스트셋에서 수행**하여 실제 성능을 왜곡 없이 측정했다.
2. **AI 생성 사기 콘텐츠 판별기** — 피싱 문자·투자 리딩방 스크립트를 입력하면 위험도 점수와 함께 구체적인 위험 신호(red flag)를 함께 제시한다. 별도의 라벨링된 학습 데이터 없이도 최신 사기 수법에 대응할 수 있도록 LLM 기반 판별 방식을 채택했다.
3. **레드팀 시뮬레이터** — 버튼 클릭 한 번으로 새로운 유형의 가상 공격 샘플을 생성하고, 그 즉시 블루팀이 탐지하는 과정을 라이브로 보여준다. "공격이 어떻게 만들어지고 어떻게 잡히는가"를 하나의 화면에서 확인할 수 있다.
4. **맞춤 대응 챗봇** — 탐지된 위험도에 따라 실제 한국 제도(경찰청 112, 금융감독원 1332, 명의도용 방지 서비스 등)를 활용한 구체적 행동 단계를 안내한다.

## 4. 차별화 포인트

- **정적 필터가 아닌 대립적 구조**: 알려진 패턴만 걸러내는 기존 방식과 달리, 레드팀이 신종 수법을 선제적으로 시뮬레이션해 블루팀의 대응 범위를 계속 넓힌다.
- **검증 가능한 성능**: 사기 탐지 모델의 recall/precision/ROC-AUC를 실제 홀드아웃 테스트셋에서 측정해 공개한다 (하단 5번 참고).
- **실사용 가능한 대응 정보**: 심리적 경고에 그치지 않고, 한국 실정에 맞는 실제 신고·지급정지 절차를 안내한다.

## 5. 기술 구현 현황 (2026-08-23 기준)

| 항목 | 내용 |
|---|---|
| 이상거래 탐지 모델 | XGBoost + SMOTE(학습 데이터에만 적용). 테스트셋(56,962건, 사기 98건) 기준 **recall 87.8%, precision 74.8%, F1 0.81, ROC-AUC 0.981** |
| 텍스트 판별 / 레드팀 / 가이드 | Google Gemini API (무료 티어), 구조화 JSON 출력으로 안정적 파싱 |
| 백엔드 | FastAPI, REST API 4종 (`/api/transactions/score`, `/api/messages/analyze`, `/api/redteam/generate`, `/api/guidance`) |
| 프론트엔드 | Next.js — 메인 분석 화면, 레드팀 vs 블루팀 라이브 데모 화면 |
| 배포 | Vercel(프론트) + Render(백엔드), 전 구간 무료 티어 |

> 본 MVP는 실제 은행 거래 데이터가 아닌 공개 벤치마크 데이터셋 기반 PoC이며, 레드팀이 생성하는 공격 샘플은 데모/검증 목적의 가상 콘텐츠로 실제 인물·기관과 무관함을 명시한다.

## 6. 기대 효과

- **금융소비자**: 실시간으로 사기 의심 콘텐츠를 판별하고, 당황하지 않고 즉시 취할 행동을 안내받아 실제 피해로 이어지기 전에 대응할 수 있다.
- **금융기관**: 신종 사기 패턴에 대한 조기경보 체계로 활용 가능하며, 레드팀 시뮬레이션 결과를 자체 보안 교육 자료로도 응용할 수 있다.
