# 기능명세서 — AI 금융보안 비서

## 1. 전체 구조

```
[Next.js 프론트엔드] --REST(JSON)--> [FastAPI 백엔드] --+--> [학습된 XGBoost 모델 (로컬 추론)]
                                                          +--> [Google Gemini API (텍스트 판별/레드팀/가이드)]
```

## 2. 화면 목록

| 화면 | 경로 | 설명 |
|---|---|---|
| 메시지 분석 (메인) | `/` | 사용자가 의심스러운 문자/메시지를 붙여넣으면 위험도와 대응 가이드를 출력 |
| 레드팀 vs 블루팀 데모 | `/demo` | 버튼 클릭 시 레드팀이 가상 공격 샘플을 생성하고, 블루팀이 즉시 분석하는 과정을 실시간으로 보여줌 |

### 2.1 메시지 분석 화면 (`/`)
- 입력: 텍스트 영역 (자유 형식 메시지 붙여넣기)
- 동작: "분석하기" 클릭 → `/api/messages/analyze` 호출 → 결과 수신 즉시 `/api/guidance` 호출
- 출력: 위험도(원형 게이지 + %), 사기 의심 여부, 판단 근거, 위험 신호 태그 목록, 위험도별 대응 요령(단계별)
- 예외 처리: API 실패 시 에러 메시지 표시, 입력 비어있으면 버튼 비활성화
- 하단 **이상거래 탐지 체험** 섹션: "정상 거래 샘플" / "이상거래 샘플" 버튼 클릭 → `/api/transactions/examples`에서 실제 데이터셋 샘플을 가져와 `/api/transactions/score`로 채점, 동일한 위험도 게이지로 결과 표시

### 2.2 레드팀/블루팀 데모 화면 (`/demo`)
- 동작: 페이지 진입 시 **자동으로 1회 실행**되며, "새 공격 시뮬레이션 실행" 버튼으로 재실행 가능
  1. `/api/redteam/generate` 호출 → 레드팀 패널 즉시 표시
  2. 생성된 샘플을 `/api/messages/analyze`에 전달 → 블루팀 패널에 위험도/판단 근거 표시
  3. 분석 결과를 `/api/guidance`에 전달 → 블루팀 패널 하단에 "권장 조치" 한 줄 표시
- 출력: 좌측(레드팀) — 공격 유형, 생성된 가상 샘플 / 우측(블루팀) — 위험도, 탐지 여부, 판단 근거, 권장 조치
- 실행 이력은 화면 상단에 누적 표시(최신 순)

## 3. API 명세

### 3.1 `POST /api/transactions/score` — 이상거래 탐지
| 필드 | 타입 | 설명 |
|---|---|---|
| 요청 `features` | `number[]` (29개) | 거래 특성 벡터 (`/api/transactions/schema`로 순서 확인 가능) |
| 응답 `risk_score` | `number` (0~1) | 사기 확률 |
| 응답 `is_anomalous` | `boolean` | risk_score ≥ 0.5 여부 |

`GET /api/transactions/schema` — 모델이 기대하는 feature 이름 목록 반환.
`GET /api/transactions/examples` — 데모용 실제 정상/이상거래 샘플(각 29-feature 벡터) 반환. 원본 CSV는 배포 환경에 포함하지 않으므로, 학습 시점에 실제 데이터셋에서 추출해 `backend/app/ml/examples.json`으로 고정.

### 3.2 `POST /api/messages/analyze` — AI 생성 사기 콘텐츠 판별
| 필드 | 타입 | 설명 |
|---|---|---|
| 요청 `text` | `string` | 분석할 메시지 원문 |
| 응답 `risk_score` | `number` (0~1) | 사기 가능성 |
| 응답 `is_likely_scam` | `boolean` | 사기 의심 여부 |
| 응답 `reasoning` | `string` | 판단 근거 (한국어 설명) |
| 응답 `red_flags` | `string[]` | 감지된 위험 신호 목록 |

### 3.3 `POST /api/redteam/generate` — 레드팀 공격 샘플 생성 (데모 전용)
| 필드 | 타입 | 설명 |
|---|---|---|
| 요청 | 없음 | 4가지 공격 유형 중 무작위 선택 |
| 응답 `sample_text` | `string` | 생성된 가상 공격 샘플 (실제 인물/기관 무관) |
| 응답 `attack_type` | `string` | 공격 유형 라벨 |

### 3.4 `POST /api/guidance` — 맞춤 대응 가이드
| 필드 | 타입 | 설명 |
|---|---|---|
| 요청 `risk_score` | `number` | 위험도 점수 |
| 요청 `context` | `string` | 상황 설명(원문 메시지 등) |
| 응답 `risk_level` | `string` | "낮음" / "중간" / "높음" |
| 응답 `steps` | `string[]` | 단계별 행동 요령 (한국 실제 신고 채널 포함) |

## 4. 데이터 및 모델

| 항목 | 내용 |
|---|---|
| 학습 데이터 | 신용카드 이상거래 공개 벤치마크 데이터셋 (OpenML `creditcard`, 284,807건, 사기 492건) |
| 전처리 | Train/Test 8:2 분할(계층 샘플링) → 학습 데이터에만 SMOTE 오버샘플링 적용 |
| 모델 | XGBoost Classifier (n_estimators=300, max_depth=5) |
| 검증 결과 | recall 87.8%, precision 74.8%, F1 0.81, ROC-AUC 0.981 (원본 비율 테스트셋 기준) |
| 텍스트 판별/레드팀/가이드 | Google Gemini API, `response_schema` 지정 구조화 JSON 출력 |
